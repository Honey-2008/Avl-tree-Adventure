Quick Lesson

What is an AVL Tree?

An AVL tree is a Binary Search Tree that automatically keeps itself balanced.

⚖️ Balance Factor

Balance Factor = Height(Left) − Height(Right)

Valid values: -1, 0, +1

🔄 Rotations

AVL trees use rotations when a node becomes unbalanced.
